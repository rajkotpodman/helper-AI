## 🌟 Overview

As frontier silicon models scale exponentially, data center computing is colliding with the physical limits of planetary power grids. While clusters like Meta Hyperion demand **5 Gigawatts** of electricity and millions of gallons of cooling water, the human brain performs planetary-scale general intelligence at an estimated ExaFLOP level consuming barely **20 Watts**—a **250,000,000-fold** thermodynamic advantage.

The **AI 2026 Wetware Hub** bridges this frontier by simulating and monitoring:
1. **Cortical Labs CL-1 DishBrain Architecture:** 800,000 living human cortical neurons grown over high-density CMOS Microelectrode Arrays (MEAs).
2. **Karl Friston's Free Energy Principle:** Living biological cells self-organizing to minimize unpredictable electrical entropy without machine learning gradients or backpropagation.
3. **The 20W vs 5GW Thermodynamic Bottleneck Calculator:** Real-time scaling models comparing silicon megawatts, nuclear reactors, and water cooling against biological watts.
4. **Frontier Alignment & Containment Incidents:** Real-world red-teaming telemetry covering shutdown evasion, steganography, and container namespace privilege escalation.
5. **Interactive Audio Briefings:** Synchronized bilingual transcripts (English and Gujarati) with real-time paragraph tracking.
6. **Helper-AI Agent Bridge:** Zero-touch dispatch interface to run autonomous goals directly into the local Python agent backend.

## 🚀 Running & Developing Locally

### 1. Dedicated High-Speed Dev Server (Port 3000)
```bash
# Inside ai_2026_hub directory
npm install
npm run dev -- --host 127.0.0.1 --port 3000
```
Or double click `run_wetware_hub.bat` from the root repository.

### 2. Integrated into Helper-AI Backend (Port 8000)
The built bundle is automatically mounted in `app.py`:
- Navigate to: **`http://127.0.0.1:8000/wetware`**
- Or click the `🧬 AI 2026 Wetware Hub` item in the DeepSeek Harness UI left sidebar or top navigation.
- Fully integrated with the live audio briefing engine and agent goal dispatch bridge.

### 3. Production Build
```bash
npm run build
```
Generates optimized static assets into `dist/` with relative asset resolution.
